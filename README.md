# Arduino MacroPad PRO

Самодельный макропад на базе Arduino Uno с графическим интерфейсом на Python (CustomTkinter). Позволяет управлять компьютером с помощью физических кнопок.

## Возможности
- Подключение к Arduino через COM-порт.
- Настройка действия для каждой кнопки.
- Запуск любых .exe программ с кнопки.
- Быстрые команды: Свернуть все окна (Win+D), Заблокировать ПК (Win+L), Скриншот, Alt+Tab и другие.
- Оптимизированный код (потребляет менее 3% ЦП в фоне).

## Компоненты
- Arduino Uno (или совместимая плата).
- 2 тактовые кнопки.
- Провода.
- USB-кабель.

## Схема подключения
- Кнопка 1: один контакт в GND, второй в Pin 2.
- Кнопка 2: один контакт в GND, второй в Pin 4.
Используется встроенная подтяжка INPUT_PULLUP, резисторы не нужны.

## Файлы проекта
- macropad_app.py — основной код программы (интерфейс и логика).
- arduino_sketch.ino — прошивка для Arduino.
- requirements.txt — список зависимостей для Python.

## Установка и запуск
1. Установите Python (при установке обязательно поставьте галочку "Add Python to PATH").
2. Установите библиотеки:
   pip install -r requirements.txt
3. Залейте скетч в Arduino через Arduino IDE.
4. Запустите программу:
   python macropad_app.py
