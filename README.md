# Arduino MacroPad

Самодельный макропад на базе Arduino Uno с графическим интерфейсом на Python (CustomTkinter). Позволяет управлять компьютером с помощью физических кнопок.

## Установка (для пользователей)

Самый простой способ запустить программу — использовать готовый установщик.

1. Перейдите в раздел **Releases** (Релизы) на правой панели этой страницы.
2. Скачайте последний файл **MacroPad_Setup.exe**.
3. Запустите скачанный файл и следуйте инструкциям мастера установки.
4. После установки на Рабочем столе появится ярлык **Arduino MacroPad**. Запускайте программу через него.
5. Прошейте Arduino: Зайдите в папку с проектом, откройте файл arduino_sketch.ino в Arduino IDE и загрузите скетч в вашу плату Arduino Uno

*Примечание: Установщик автоматически проверит наличие Python на вашем компьютере и установит необходимые библиотеки (pyserial, customtkinter), если их нет.*

## Запуск из исходного кода (для разработчиков)

Если вы хотите запустить программу напрямую через Python или внести изменения в код:

1. **Прошейте Arduino:** Зайдите в папку с проектом, откройте файл `arduino_sketch.ino` в Arduino IDE и загрузите скетч в вашу плату Arduino Uno.
2. **Установите Python:** Если у вас его нет, скачайте с официального сайта python.org. При установке обязательно поставьте галочку **"Add Python to PATH"**.
3. **Установите библиотеки:** Откройте терминал и выполните команду:
   pip install pyserial customtkinter
4. **Запустите программу:** Выполните файл `macropad_app.py`:
   python macropad_app.py

## Компоненты
- Arduino Uno (или совместимая плата).
- 2 тактовые кнопки.
- Провода.
- USB-кабель.

## Схема подключения
- Кнопка 1: один контакт в GND, второй в Pin 2.
- Кнопка 2: один контакт в GND, второй в Pin 4.
Используется встроенная подтяжка INPUT_PULLUP, резисторы не нужны.

## Файлы проекта
- macropad_app.py — основной код программы (интерфейс и логика).
- arduino_sketch.ino — прошивка для Arduino.
- requirements.txt — список зависимостей для Python.
